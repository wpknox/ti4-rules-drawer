# TI4 Rules Drawer

A Chrome extension that adds a slide-out, searchable *Twilight Imperium 4* rules reference to [TI Assistant](https://ti-assistant.com). Built for playing with one laptop driving TI Assistant on a TV: open the drawer, look up a rule, close it, without leaving the game.

Rules content comes from [tirules-search](https://github.com/wpknox/tirules-search) (which includes Dane's official rulings) and is bundled into the extension, so it works offline and opens instantly.

## Using it

| Key (Mac: ⌥ = Option) | What it does |
|---|---|
| `/` | Open the drawer and focus search (from anywhere on TI Assistant) |
| `⌥R` / `Alt+R` | Toggle the drawer (also: click the toolbar icon or the **Rules** tab on the right edge) |
| `⌥H` / `Alt+H` | Go to the Home screen (recent searches, all rules) |
| `⌥←` `⌥→` / `Alt+←` `Alt+→` | Back / forward through drawer history |
| `Esc` | Close the drawer |
| `↑` `↓` then `Enter` | While typing, pick a page by title from the suggestions |
| `Enter` | Search the full text of every page |
| `N` / `Shift+N` | Next / previous match on the current page |

- **Search results** list every page that mentions your text, with snippets labeled by section (or card name). Click a page title to jump to its first match, or click a specific snippet to jump to *that exact* match. All matches are highlighted, and the yellow bar steps through them.
- **Dane rulings** are highlighted in gold, as on the website.
- **Recent searches** and **recently viewed** pages show on the Home screen.
- **A− / A+** change the text size, and you can drag the drawer's left edge to resize it. Both are remembered.

## Installing (developer mode)

1. Open `chrome://extensions` and turn on **Developer mode** (top right).
2. Click **Load unpacked** and select the `extension/` folder.
3. Open or reload a TI Assistant tab and press `/`.

After changing any extension files, click the reload icon on the extension's card in `chrome://extensions`, then reload the TI Assistant tab.

## Installing in Safari

The Safari version is the same `extension/` code wrapped in a small Mac app (Xcode project in `safari/`).

```bash
sh scripts/build-safari.sh    # builds, installs to ~/Applications, and launches the app once
```

Then in Safari:

1. **Settings → Advanced →** check **Show features for web developers** (adds the Develop menu).
2. **Develop → Allow Unsigned Extensions** (asks for your password). Safari turns this off each time it quits.
3. **Settings → Extensions →** check **TI4 Rules Drawer**.
4. On ti-assistant.com, click the extension's toolbar icon and choose **Always Allow on This Website**.

After changing anything in `extension/`, re-run `scripts/build-safari.sh`, since Safari bundles a copy at build time.

## Updating the rules

The rules are a snapshot of a local clone of tirules-search. After pulling or editing the rules repo:

```bash
node scripts/build-rules.mjs path/to/tirules-search
TIRULES_DIR=path/to/tirules-search node scripts/build-rules.mjs   # or set it once in your shell profile
node scripts/build-rules.mjs                                      # uses ../tirules-search if it exists
```

The drawer's "Rules from …" credit links to that folder's `origin` remote, so building from a fork credits the fork.

This rewrites `extension/rules.json`. Then reload the extension.

## Trying it without installing

`dev/harness.html` loads the content script into a fake page with stand-ins for the Chrome APIs it uses:

```bash
python3 -m http.server 8765
# open http://localhost:8765/dev/harness.html and press /
```

## Layout

```
extension/
  manifest.json     Manifest V3; runs only on ti-assistant.com
  content.js        Drawer UI, search, highlighting, history, keyboard shortcuts
  drawer.css        Styles (inside a shadow root, so they can't affect TI Assistant)
  background.js     Toolbar button and Alt+R
  rules.json        Generated by scripts/build-rules.mjs, do not edit by hand
  icons/
scripts/build-rules.mjs
dev/harness.html, dev/icon.svg
```
